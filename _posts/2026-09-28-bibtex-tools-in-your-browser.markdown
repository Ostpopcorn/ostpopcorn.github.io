My workflow with BibLaTeX is a bit messy when it is time to finalize the publishable version:
- A mixture of Unicode formatting,
- A mixture of BibTeX and BibLaTeX,
- Half of the sources have abbreviated journal names,
- Sources I added but chose not to cite, and
- Multiple .bib files from collaborators.

I bet BibTeX Tools can help.

## What is BibTeX Tools?
For all of you with similar issues, BibTeX Tools can help you clean up your .bib files.

The tool was developed by a colleague of mine, [Karl-Ludwig Besser](https://klb2.gitlab.io/), as a [command-line tool](https://github.com/klb2/bibtex-tools).

## Features

### Find duplicate entries
Tired of finding that \[2\] and \[13\] are the same paper? The tool compares titles, authors, and venues to find duplicates, both within one .bib file and across several. When it is time to merge, you can review each pair interactively or simply keep the longer entry.

### Filter on cited sources
Tired of manually trimming unused sources before uploading to arXiv? Simply upload your .bbl file and the tool will remove every entry that was not cited during compilation.

### Automatic abbreviation
Forgot how to abbreviate a specific conference title? Using the [pyiso4](https://pypi.org/project/pyiso4/) Python package, the tool abbreviates journal and conference titles according to the ISO 4 standard.

### Normalise fields
How should this field be written in BibLaTeX? The tool cleans up legacy BibTeX habits: month names become numbers, `17-61` becomes `17--61`, author names are written as `Last, First`, acronyms in titles are protected with braces, and arXiv eprints are written in one consistent style.

### Remove fields
Why did no one remove the abstract? The tool can remove specific fields, such as `abstract` or `file`, from all entries.

### Remaining features
Unicode conversion, macro expansion, generating citation keys, and removing comments from the file.

## BibTeX Tools in your browser
I hacked together a web-based application that lets you run this fantastic tool directly in your browser. A benefit with the web version is that you can chain all operations and it also provides an interactive preview. 

The app runs the original Python code via [Pyodide](https://pyodide.org) (Python compiled to WebAssembly), so **your .bib files never leave your browser**. The only outside request is optional: looking up arXiv categories for eprints sends the arXiv IDs to arXiv's public API.

We can now see two files in the top left, as well as both files after each other in the left pane. 
Note that the warnings about missing entries under the .bbl upload are gone, that is good, no sources are missing.
The right pane also has more content, since the output is from both uploaded bib files.
However, there is now a highlight that we may have two duplicate entries. We press the button to review them one by one.


[![The duplicate review dialog: shannon1948 is kept and Shannon1948mathematical will be removed]({{ '/assets/bibtex-tools-images/4-duplicates.webp' | relative_url }})]({{ '/assets/bibtex-tools-images/4-duplicates.webp' | relative_url }})

We keep the left entry. Since both keys are cited, the kept entry also gets the other key in its ids field, so both \cite commands keep working.

The bib file is now trimmed and ready for publication!
